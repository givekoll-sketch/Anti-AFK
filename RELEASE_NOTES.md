# Anti-AFK 1.0.3

Срочное исправление запуска автоматических действий для Minecraft.

## Исправления

- Первое действие теперь выполняется сразу после запуска, а не после ожидания полного интервала.
- Если Minecraft не в фокусе, приложение автоматически повторяет проверку примерно раз в 2 секунды и выполняет действие, как только выбранное окно игры станет активным.
- Проверка выбранного окна теперь использует PID процесса, а не точное совпадение заголовка окна.
- После успешного действия сохраняется выбранный пользователем интервал до следующего действия.
- Повторяющиеся предупреждения об ожидании фокуса ограничены, чтобы журнал не заполнялся одинаковыми сообщениями.

## Совместимость версий

Версия **1.0.2.1** содержит четыре числовые части и не является корректной SemVer-версией, необходимой `electron-updater`. Поэтому этот совместимый срочный патч выпущен как **1.0.3**. Функции языка, оформления и анимаций, ранее запланированные на v1.0.2.2, перенесены на **v1.0.4**.

## Установка

Скачайте `Anti-AFK-Setup-1.0.3.exe` из раздела **Assets**, запустите установщик и следуйте инструкциям. Установщик не подписан сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen.

> Действия отправляются только в выбранное окно Minecraft, когда оно находится на переднем плане. Проверьте правила своего Minecraft-сервера: некоторые серверы запрещают автоматизацию.
