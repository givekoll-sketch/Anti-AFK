# Anti-AFK 1.0.0

Первый публичный выпуск Anti-AFK — компактного Windows-приложения для управления активностью в Minecraft Java и Bedrock.

## Что нового

- Поиск открытых окон Minecraft.
- Выбор действий: поворот камеры, прыжок и движение вперёд.
- Настраиваемый интервал от 5 секунд.
- Быстрое управление клавишами `F6`, `F7` и `F8`.
- Сохранение конфигурации и светлая/тёмная темы.
- Проверка обновлений и установка прямо из приложения.
- Фирменные иконки и удобный Windows-установщик.

## Установка

Скачайте `Anti-AFK-Setup-1.0.0.exe` из раздела **Assets**, запустите установщик и следуйте инструкциям. Windows может показать предупреждение SmartScreen, поскольку приложение пока не подписано сертификатом издателя.

> Перед использованием проверьте правила своего Minecraft-сервера: некоторые серверы запрещают автоматизацию.
